# Vesti+

Site demonstrativo do projeto **Vesti+** (guarda-roupa compartilhado por assinatura), feito para a Feira Cultural/Científica do Colégio Estadual Souza Naves. Projeto de Educação Financeira, 1ª série B do Ensino Médio.

Todos os valores e a operação mostrados são simulações educacionais.

## Estrutura

```
vesti-mais/
├── index.html      # estrutura da página
├── css/style.css   # estilos (temas claro e escuro)
├── js/script.js    # sacola, calculadoras, simulador e contador de moedas
└── assets/logo.png # logo do Vesti+
```

## Como rodar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos (mantendo as pastas).
2. Em **Settings > Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`.
3. Aguarde alguns minutos: o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
